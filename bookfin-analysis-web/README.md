# KLineChart Preview
KLineChart features preview.

## Run
```
npm run dev
```

## Links
+ [KLineChart](https://github.com/klinecharts/KLineChart)
+ [Pro](https://github.com/klinecharts/pro)

### Saved chart preferences

Indicator selection, visibility and calculation parameters persist in this browser,
including parameters of temporarily disabled indicators. General Pro settings
(theme, chart styles, locale, timezone, selected symbol and period) use
`bookfin:workspace-settings:v1`. Overlay storage remains scoped by symbol/period.
Preferences are local to the browser/origin, not synchronized across devices.
